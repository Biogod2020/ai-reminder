# SOTA Report: Cognitive Reward Circuits in AI Agents (2024-2025)

## Executive Summary
SOTA in 2025 has moved from simple 'gamification' to **Dopamine-Aware Design**, where AI agents manage a user's attention and motivation as finite neuro-economic resources. The goal is to support executive function through **Reward Prediction Error (RPE)** optimization and **Agentic Cognitive Offloading**.

## Current State (SOTA)
- **Neuro-Economic Optimization:** AI models (arXiv:2501.02368) that gate notifications and interventions based on real-time cognitive load and emotional states.
- **Distributional RPE Coding:** Inspired by biological hardware, agents now model a **probabilistic map** of future rewards (Optimistic vs. Pessimistic outcomes) to help users navigate uncertainty.
- **Action-Contingent Gating:** Dopamine signals (and AI rewards) are attenuated if action isn't initiated, preventing 'reward fatigue' when the user is in a low-energy window.

## Key Technologies/Frameworks
- **Personalized Narrative Reframing:** reframing mundane tasks as 'epic quests' (e.g., Leantime) to trigger dopamine in neurodivergent users.
- **TITANS Architecture:** Uses 'surprise-based' memory updates (high-RPE events) to prioritize learning and long-term potentiation.
- **Bayesian Reinforcement Learning:** Adjusts learning rates ($lpha$) based on environmental volatility and uncertainty.

## Expert Consensus & Trends
- **Architecture of Coping:** AI should offload low-level planning to free up 'germane' load for creative work.
- **Digital Detox framing:** Using LLMs to promote sustained cognitive interaction rather than instant, shallow hits.
- **Trend:** Apps that self-regulate to prevent overstimulation and 'dopamine dependency'.
