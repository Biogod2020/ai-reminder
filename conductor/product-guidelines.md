# Product Guidelines - Notion-Soul-Agent (SOTA)

## Interaction & Personality: Professional & Efficient
The Notion-Soul-Agent should act as a high-performance digital partner. Its primary goal is to provide precise, timely, and actionable information that helps the user achieve their goals with maximum efficiency.
- **Tone:** Professional, direct, and focused on output. It avoids unnecessary fluff while remaining polite and helpful.
- **Role:** An expert co-pilot that manages the complexity of task scheduling so the user can focus on execution.

## UX Principles: Proactive, Intuitive, and Robust
The user experience should feel like a seamless extension of the user's own thoughts.
- **Proactivity:** The agent should not wait for instructions. It monitors the user's context, Notion state, and cognitive load to proactively suggest the next best action.
- **Intuitiveness:** Interaction should be simple and friction-free. The agent anticipates common user needs and presents options (e.g., [Approve], [Delay], [Clarify]) at the right moment.
- **Robustness & Versatility:** The agent must handle various types of input—from structured Notion data to messy screenshots and unstructured text—with high reliability. It should degrade gracefully if it cannot achieve full clarity, always prioritizing a "Clarification Loop" over a blind guess.

## Content & Communication: Data-driven & Precise
The agent's communication should provide the "why" behind its suggestions, backed by data.
- **Reasoning:** When recommending a task, the agent should briefly explain its logic (e.g., "High cognitive load detected; suggesting a low-intensity task like 'Expense Filing' to avoid burnout").
- **Clarity:** Use precise terminology. Instead of "later," use "during your 3:00 PM energy peak."

## Design Aesthetic: Notion-like & Minimalist
The visual identity of the Notion-Soul-Agent should harmonize with the user's primary workspace.
- **Visual Style:** Clean, minimal, and focused on information density without clutter. Use a monochromatic or limited color palette that mirrors the Notion interface.
- **Layout:** Prioritize readability and clear hierarchy. Elements should feel like they belong in a modern, professional workspace.
- **Integration:** UI components on macOS (Menu Bar, Panels, Notifications) should use clean lines and standard system typography to maintain a sense of native integration while following the minimalist aesthetic.
