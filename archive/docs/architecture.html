Node Specifications

User Input / Dashboard

Client

The entry point for natural language requests and behavioral feedback. Triggers the Orchestrator loop via API.

Input
  • • User Query
  • • UI Actions
Output
  • • API Trigger

classify (Node)

AI Node

Uses global context (Memory + Current Tasks) to route user intent to specialized handlers.

Input
  • • user_input (str)
  • • global_context
Output
  • • intent (str)

handle_task (Node)

AI Node

Decomposes goals into atomic subtasks using ADaPT. Persists task tree to SQLite with 'pending' sync status.

Input
  • • user_input
  • • habit_context
Output
  • • Subtask Tree
  • • Logic Narrative

handle_memory (Node)

AI Node

Extracts durable facts or habits. Updates the internal SQLite 'user_soul' table and triggers long-term memory sync.

Input
  • • user_input
Output
  • • Soul Fact (DB)

handle_planner (Node)

AI Node

Analyzes schedule density and cognitive load to propose optimized re-planning of tasks.

Input
  • • Tasks [UT]
  • • Load Metrics
Output
  • • Proposed Plan

handle_clarify (Node)

AI Node

Generated MCQ (Minimal Clarification Questions) when intent confidence is low (< 0.8).

Input
  • • vague_input
Output
  • • Clarification MCQ

await_approval (Node)

Wait State

Suspends graph execution until user explicitly approves proposed tasks or schedule changes.

Input
  • • proposed_actions
Output
  • • User Signal

notify (Node)

Action

Dispatches macOS native notifications or Bark push alerts for completed syncs or critical nudges.

Input
  • • notify_payload
Output
  • • OS Alert / Push

evaluate_nudge (Heartbeat)

Proactive

Async loop that monitors 'in_progress' tasks. If duration exceeds estimate, triggers empathy-based nudge.

Input
  • • Task Status
  • • Time Elapsed
Output
  • • Nudge Decision

get_optimized_view (API)

API

FastAPI endpoint that serves scientifically interleaved tasks (Hard/Soft interleaving) to the UI.

Input
  • • Tasks [UT]
Output
  • • View JSON

VisualSampler

System

Captures 15s interval Retina screenshots. Processes RGBA to RGB and compresses to JPEG 85 quality.

Input
  • • Retina Screen
Output
  • • JPEG Frame

KnowledgeDB

System DB

Direct interface to macOS knowledgeC.db. Extracts ZOBJECT and ZSTRUCTUREDINSTANCE for app timelines.

Input
  • • SQLite Binary
Output
  • • App Timeline

BehaviorSynthesisEngine

Core Logic

Orchestrates Dual-Axis truth. Feeds image batches to Gemini and merges results with system logs.

Input
  • • Image Batch
  • • App Timeline
Output
  • • Behavior Truth

Gemini 3.1 (Vision)

VLM

Analyzes visual frames to determine semantic intent, focus scores, and identifies key moments.

Input
  • • Frames + Prompts
Output
  • • Intent Axis

DualAxisMerger

Algorithm

Aligns asynchronous visual points with system duration blocks. Implements temporal gap-filling logic.

Input
  • • System Axis
  • • AI Axis
Output
  • • Merged Omni Log

notion_soul.db

Database

Primary SQLite storage with WAL enabled. Stores omni_behavior_log, tasks, and user_soul state.

Input
  • • Raw Logs
Output
  • • Structured Data

Tasks [UT] Table

Logic DB

Database view of all scheduled work. Tracked via 'sync_status' for eventual write-back to Notion.

Input
  • • Proposed Steps
Output
  • • Scheduled Work

MemoryConsolidator

Agent

Distills daily raw logs into habit summaries. Compresses Time-Pyramid (1D -> 3D -> 7D -> 30D).

Input
  • • Omni Logs
Output
  • • Summaries

user_soul.md

Context

The Markdown 'Brain' of the user. Read as 1M context injection for every AI decision.

Input
  • • Summaries
Output
  • • 1M Context

END

Terminal

The terminal state of the SoulOrchestrator graph. Indicates completion of the current processing turn.
