Title: InfantAgent-Next: A Multimodal Generalist Agent for Automated Computer Interaction\nURL: https://arxiv.org/abs/2505.10887\n\nAbstract:\nThis paper introduces InfantAgent-Next, a generalist agent capable of interacting with computers in a multimodal manner, encompassing text, images, audio, and video. Unlike existing approaches that either build intricate workflows around a single large model or only provide workflow modularity, our agent integrates tool-based and pure vision agents within a highly modular architecture, enabling different models to collaboratively solve decoupled tasks in a step-by-step manner. Our generality is demonstrated by our ability to evaluate not only pure vision-based real-world benchmarks (i.e., OSWorld), but also more general or tool-intensive benchmarks (e.g., GAIA and SWE-Bench). Specifically, we achieve 7.27%% accuracy on OSWorld, higher than Claude-Computer-Use.\n\nKey Architectural Components:\n* Modular Architecture: A decoupled system that allows different models to handle specific sub-tasks.\n* Hybrid Agent Integration: Combines tool-based agents (for text/code tasks) with pure vision agents (for GUI interaction).\n* Multimodal Processing: Native support for text, images, audio, and video inputs to facilitate comprehensive computer interaction.\n* Step-by-Step Task Solver: A collaborative execution engine where models work sequentially to solve complex, multi-stage problems.
