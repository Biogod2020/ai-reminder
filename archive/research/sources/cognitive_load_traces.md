Title: Cognitive Load Traces (CLTs): A Mid-Level Interpretability Framework for Deep Models\nURL: https://arxiv.org/abs/2510.15980\n\nAbstract:\nWe propose Cognitive Load Traces (CLTs) as a mid-level interpretability framework for deep models, inspired by Cognitive Load Theory in human cognition. CLTs are defined as symbolic, temporally varying functions that quantify model-internal resource allocation. Formally, we represent CLTs as a three-component stochastic process (IL_t, EL_t, GL_t), corresponding to Intrinsic, Extraneous, and Germane load. Each component is instantiated through measurable proxies such as attention entropy, KV-cache miss ratio, representation dispersion, and decoding stability. We propose both symbolic formulations and visualization methods (load curves, simplex diagrams) that enable interpretable analysis of reasoning dynamics. Experiments on reasoning and planning benchmarks show that CLTs predict error-onset, reveal cognitive strategies, and enable load-guided interventions that improve reasoning efficiency by 15-30%% while maintaining accuracy.\n\nCognitive Load Types Identified:\n* Intrinsic Load (IL_t): Relates to the inherent difficulty of the task.\n* Extraneous Load (EL_t): Relates to resources wasted on irrelevant processing or architectural inefficiencies.\n* Germane Load (GL_t): Relates to the effort dedicated to constructing and processing schemas or 'deep' reasoning.\n\nMonitoring Methodologies:\n* Measurable Proxies: Attention Entropy, KV-cache Miss Ratio, Representation Dispersion, Decoding Stability.\n* Visualization Methods: Load Curves, Simplex Diagrams.\n* Symbolic Formulations: Three-component stochastic process (IL_t, EL_t, GL_t).
