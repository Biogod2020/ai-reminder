Node Specifications

User Input / Dashboard

Client

The entry point for natural language requests and behavioral feedback. Triggers the Orchestrator loop.

classify

AI Node

Determines user intent by analyzing input against long-term habits (UserSoul) and current Task DB schedule.

Input
  • • user_input (str)
  • • user_soul.md (Context)
  • • Tasks [UT] (Current)
Output
  • • intent (task|memory|...)

handle_task

AI Node

Decomposes complex goals into atomic subtasks. Writes the resulting task tree directly to the Task DB.

Input
  • • user_input
  • • user_soul.md
Output
  • • Task DB (New Tree)
  • • narrative (str)

handle_memory

AI Node

Extracts habits or preferences from input and persists them to the Soul Fact table in SQLite.

handle_planner

AI Node

Performs scientific rescheduling of the entire day/week by reading and writing to the Tasks [UT] Table.

evaluate_nudge (Heartbeat)

Proactive Node

Regularly checks current task status against schedule. Decides if an empathetic nudge is required based on cognitive load.

get_optimized_view (API)

API Node

Fetches tasks and applies SOTA Interleaving logic to present a scientifically optimized schedule view to the Dashboard.

VisualSampler

System

Captures screenshots every 15s, performs RGB conversion and quality optimization for AI vision ingestion.

BehaviorSynthesisEngine

Core Logic

Orchestrates Dual-Axis synthesis by aligning system app logs with AI visual intent from screenshots.

DualAxisMerger

Algorithm

Performs point-to-point overlay of visual intent and app blocks, applying inertia smoothing to fill temporal gaps.

Tasks [UT] Table

Database

The central registry for all scheduled atomic tasks. Read by classify/planner, written by handle_task/planner.

MemoryConsolidator

System Agent

Implements Time-Pyramid consolidation to distill high-volume raw logs into long-term behavioral habits in user_soul.md.

user_soul.md

Memory

The human-readable 'Digital Soul'. Provides 1M context for AI reasoning about habits and cognitive peaks.
