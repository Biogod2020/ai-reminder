Node Specifications

classify

AI Node

Determines user intent by analyzing input against long-term habits and current schedule context.

Input
  • • user_input (str)
  • • context (Soul Memory)
Output
  • • intent (task|memory|...)

handle_task

AI Node

Decomposes complex goals into atomic subtasks using ADaPT protocol and empathetic narrative generation.

Input
  • • user_input
  • • global_context
Output
  • • task_tree (json)
  • • narrative (str)

BehaviorSynthesisEngine

Core Logic

Orchestrates Dual-Axis synthesis by aligning system app logs with AI visual intent from screenshots.

Input
  • • image_batch (List[PIL])
  • • app_timeline (KnowledgeDB)
Output
  • • behavior_truth_slice

DualAxisMerger

Algorithm

Performs point-to-point overlay of visual intent and app blocks, applying inertia smoothing to fill temporal gaps.

Input
  • • system_axis
  • • ai_intent_axis
Output
  • • merged_omni_log

MemoryConsolidator

System Agent

Implements Time-Pyramid consolidation to distill high-volume raw logs into long-term behavioral habits.

Input
  • • raw_behavior_logs
Output
  • • consolidated_patterns
